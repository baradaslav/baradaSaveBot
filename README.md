# Telegram YouTube Audio Bot

Бот принимает ссылку на YouTube-видео, предлагает выбрать формат MP3 или M4A, скачивает доступную аудиодорожку через `yt-dlp`, конвертирует ее через `ffmpeg` и отправляет аудиофайл пользователю в Telegram.

Бот предназначен только для видео, на которые у пользователя есть права, разрешение автора или которые находятся в свободном доступе для такого использования. В проекте нет обхода DRM, авторизации, paywall или приватных видео.

## Получение BOT_TOKEN

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте команду `/newbot`.
3. Укажите имя и username бота.
4. Скопируйте выданный токен.

## Локальный запуск

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Добавьте токен в `.env`:

```env
BOT_TOKEN=your_real_telegram_bot_token
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите бота:

```bash
python bot.py
```

Файл `.env` нельзя пушить в GitHub, потому что в нем хранятся секреты. Он уже добавлен в `.gitignore`.

## ffmpeg

Для конвертации аудио нужен установленный `ffmpeg`.

Проверить установку можно так:

```bash
ffmpeg -version
```

Если бот пишет `ffmpeg не найден`, значит `ffmpeg` не установлен в окружении запуска или недоступен в `PATH`.

Локально на macOS можно установить через Homebrew:

```bash
brew install ffmpeg
```

Если `ffmpeg` установлен в нестандартной папке, можно указать путь через переменную окружения:

```env
FFMPEG_LOCATION=/usr/bin/ffmpeg
```

Для Render добавлен `Dockerfile`, который устанавливает `ffmpeg` через `apt-get`.

## Ошибки yt-dlp

Если бот пишет `Не удалось скачать аудио`, посмотрите вывод терминала, где запущен `python bot.py`. Там `yt-dlp` покажет реальную причину: видео недоступно, ссылка неправильная, региональное ограничение, слишком длинное видео или `HTTP Error 403`.

Для локальной проверки можно запустить:

```bash
python -m yt_dlp --no-playlist --skip-download --print title "https://www.youtube.com/watch?v=jNQXAC9IVRw"
```

Если установленный `yt-dlp` устарел:

```bash
pip install -U yt-dlp
```

## Render

Добавьте токен:

`Render -> Service -> Environment -> Add Environment Variable`

Переменная:

```env
BOT_TOKEN=your_real_telegram_bot_token
```

Настройки сервиса:

```text
Build Command:
pip install -r requirements.txt

Start Command:
python bot.py
```

Если используете Docker на Render, выберите Docker Environment. В этом случае Render возьмет настройки из `Dockerfile`, а `Build Command` и `Start Command` обычно не нужны.

Render Free может засыпать, поэтому бот иногда отвечает с задержкой после периода простоя.

## Ограничения

- Максимальная длительность видео: 20 минут.
- Итоговый файл не должен превышать лимит Telegram.
- Временные файлы сохраняются в `downloads/` и удаляются после обработки.
- Видео целиком не скачивается, если доступен отдельный аудиопоток.
